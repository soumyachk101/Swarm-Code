# Tauri Icons

Tauri 2 uses icon assets for the application window and system tray. Icons are
auto-generated by Tauri CLI from source images using the `tauri icon` command.

## Setup

Run the following to generate icons from a source image:

```bash
cd src-tauri
tauri icon /path/to/source-icon.png
```

This generates all required icon sizes and places them in `src-tauri/icons/`.

## Source

The source icon image is `../public/icon.svg` (the app icon from the original
Swarm Code project).
