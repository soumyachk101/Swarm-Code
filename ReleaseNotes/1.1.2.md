A release introducing in-picker model search and flexible provider switching in running chats. Apple silicon, macOS 26 or later.

## New features
- In-picker model search: search and filter models across all providers and Hydra pairs in real time.
- Provider switching in running chats: switch models and providers (Codex, Claude, etc.) within ongoing conversation threads while keeping history.

## Refinements
- Clearer provider branding and icons in the model picker list.
