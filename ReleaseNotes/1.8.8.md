Swarm Code 1.8.8 introduces multi-hunk diffing with context lines, eager-bounded conversation timeline rendering to eliminate macOS resize freezes, background CLI updates with turn-level transparent retries, non-blocking queued Hydra head merges, and Claude Opus 5.5 and GPT-5.6 model recipes. Apple silicon, macOS 26 or later.

## New features
- Multi-Hunk Diffing: Upgraded the diffing engine with context lines and fast prefix/suffix scanning for large files, making turn edits precise and instant.
- Background CLI Updater: Added non-blocking background CLI updates with transparent auto-retry when tools report newer requirements.
- Extended Model Support: Integrated Claude Opus 5.5 and GPT-5.6 Sol/Luna/Terra models along with updated Hydra recipes (`astra-sol`, `sol-luna`).
- Markdown Link Navigation: Added MarkdownLinkOpener support to directly jump to local workspace files and line numbers in your default editor.

## Bug fixes
- Timeline Window Freeze: Replaced lazy vertical scrolling with bounded eager timeline rendering, eliminating macOS window edge hangs and layout loops.
- Non-Blocking Hydra Merges: Transitioned Hydra landing pipeline to a non-blocking queued merge flow with automated retry on forge branch conflicts.
- Disk Cache Thrashing: Set shared URLCache disk capacity to zero and debounced library persistence to eliminate disk write thrashing during extended coding sessions.
