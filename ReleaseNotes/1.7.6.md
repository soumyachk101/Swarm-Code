Swarm Code 1.7.6 delivers guaranteed native macOS desktop notification banners, audible alert sounds, and background dock bounces across all application states (active, minimized, hidden, and background). Apple silicon, macOS 26 or later.

## Bug fixes
- Guaranteed desktop notifications: Fixed macOS notification banners not appearing when Swarm Code is minimized or working in the background. Notifications now dispatch via an independent system subprocess (`/usr/bin/osascript`), completely bypassing macOS ad-hoc signature authorization drops and delivering instant native banners and chimes.
- Dock attention request: Bounces the dock icon when tasks finish while Swarm Code is minimized or another application is active.
- Safe argument passing: Native notification parameters are passed directly via argv, eliminating all escaping and special character risks.
